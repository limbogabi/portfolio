Chess Coach

Live demo

Socratic chess coaching with engine ground truth

A full-stack web app where students manage long-term chess analysis with an AI coach — pasting PGN/FEN positions or uploading a chess.com/lichess screenshot (parsed via Claude’s vision), then getting coached through it via guided questions rather than direct answers, mirroring how a real human coach builds independent analytical skill instead of handing over the best move. Includes a branching move-tree UI (Lichess-Study style), a from-scratch board editor, and a lightweight beta-access system with admin-gated approval and per-user token budgeting.

  • Hybrid coaching architecture: Claude handles pedagogy (Socratic questioning, adapting to what the student already understands), while Stockfish and chess.js supply objective ground truth — engine evaluation, legal-move validation, and even square colors are computed deterministically and fed to the model rather than left to LLM reasoning.
  • Live tool calling: for hypothetical lines (“what if I play this”), the coach can simulate and evaluate the position instead of guessing.
  • Vision input: screenshot upload from chess.com/lichess parsed into a position via Claude vision, alongside PGN/FEN paste.

Stack: Next.js, Supabase, Anthropic Claude, Stockfish (server-side), chess.js
